# Aset Desain

Kumpulan aset desain dalam satu tempat.

## Struktur folder

| Folder | Isi | Format umum |
| --- | --- | --- |
| `assets/images/` | Foto, ilustrasi, mockup, gambar produk | `.jpg`, `.png`, `.webp` |
| `assets/icons/` | Ikon dan logo | `.svg`, `.png` |
| `assets/fonts/` | File font | `.ttf`, `.otf`, `.woff2` |
| `assets/videos/` | Video, animasi, klip pendek | `.mp4`, `.mov`, `.webm` |
| `assets/audio/` | Musik, efek suara, voice over | `.mp3`, `.wav` |

## Cara menambah aset

1. Buka subfolder yang sesuai di GitHub.
2. Klik **Add file → Upload files**.
3. Seret file ke halaman, tulis keterangan singkat, lalu klik **Commit changes**.

## Aturan penamaan file

- Pakai huruf kecil dan tanda hubung, tanpa spasi: `banner-promo-november.png`
- Tambahkan ukuran atau versi bila perlu: `logo-putih-512.png`, `poster-v2.jpg`
- Hindari nama umum seperti `final.png` atau `gambar1.jpg`

## Catatan

- GitHub menolak file di atas 100 MB. Untuk video besar, kompres dulu atau simpan di tempat lain dan tulis tautannya di sini.
- File `.gitkeep` hanya penjaga agar folder kosong tetap tersimpan. Boleh dihapus setelah folder berisi file.
