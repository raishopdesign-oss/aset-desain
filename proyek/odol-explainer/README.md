# Explainer: Kenapa pasta gigi disebut odol?

Video 9:16 (Reels/TikTok) ±40 detik, gaya kolase kertas stop motion.

- `hasil/odol-draft-tanpa-vo.mp4`: hasil render, berisi efek suara tanpa voice-over.
- `index.html`: sumber animasinya. Buka dengan klik dua kali di browser. Tambahkan `?debug=1` di akhir alamat untuk panel geser waktu. Spasi untuk jeda, R untuk ulang.
- `vo-script.md`: naskah voice-over.

## Foto Karl August Lingner (opsional)

Saat ini foto Lingner diganti siluet. Untuk memakai foto aslinya (domain publik):
1. Unduh dari https://commons.wikimedia.org/wiki/File:PSM_V80_D113_Karl_August_Lingner.png
2. Simpan sebagai `img/lingner.jpg` (format JPG) di folder ini.

Animasi otomatis memakai foto itu menggantikan siluet.
