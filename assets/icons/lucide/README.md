# Lucide Icons

2.403 ikon garis dari [Lucide](https://lucide.dev) versi 1.75.0, format SVG.

## Mencari ikon

- Lihat semua ikon beserta gambarnya di https://lucide.dev/icons, lalu cari file dengan nama yang sama di folder ini. Contoh: ikon "Shopping Cart" ada di `shopping-cart.svg`.
- Di GitHub, tekan tombol `t` lalu ketik nama ikon dalam bahasa Inggris, misalnya `heart`, `phone` atau `instagram`.

## Memakai ikon

- **Canva / Figma / Illustrator:** download file `.svg`, lalu seret ke kanvas. Warna dan ukuran bisa diubah seperti objek vektor biasa.
- **Website:** salin isi file `.svg` ke HTML. Warna ikon mengikuti warna teks di sekitarnya.
- **Butuh PNG:** buka ikon di https://lucide.dev/icons lalu pilih download PNG, atau ekspor dari Canva/Figma.

Ukuran asli 24×24 px, tapi karena vektor, ikon tetap tajam di ukuran berapa pun.
