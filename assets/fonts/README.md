# Font Populer untuk Konten Kreator

11 keluarga font yang sering dipakai di konten TikTok, Instagram, dan YouTube. Semuanya dari Google Fonts, berlisensi **SIL Open Font License (OFL)**, jadi gratis untuk pemakaian pribadi maupun komersial. File lisensinya ada di `OFL.txt` di tiap folder.

Semua file berformat **TTF statis**, satu file per ketebalan, supaya bisa langsung diupload ke Canva, CapCut, Figma, Photoshop, atau di-install di komputer.

## Kombinasi yang sering dipakai

- **Bebas Neue + Montserrat**: thumbnail YouTube dan teks Reels
- **Anton + Poppins**: hook video TikTok dan caption
- **Playfair Display + Inter**: carousel edukasi yang elegan
- **DM Serif Display + Plus Jakarta Sans**: konten brand atau olshop yang terlihat premium
- **Montserrat + Caveat**: konten santai dengan aksen tulisan tangan

## Cara memakai

- **Canva (Pro):** buka **Brand → Fonts → Upload a font**, lalu pilih file `.ttf`. Catatan: Montserrat, Poppins, dan font lain di sini sebenarnya sudah tersedia gratis di Canva, jadi cukup cari namanya.
- **CapCut (PC/Mac):** klik **Text → Font → Upload/Import**, pilih file `.ttf`.
- **CapCut (HP):** simpan file `.ttf` ke HP, lalu di menu **Text → Font**, ketuk ikon tambah/impor.
- **Windows:** klik kanan file `.ttf` → **Install**.
- **Mac:** klik dua kali file `.ttf` → **Install Font**.

Download semua font sekaligus lewat tombol hijau **Code → Download ZIP** di halaman depan repo.
