# Efek Suara

20 efek suara pendek bertema kertas dan stop motion, format MP3.

Semua suara dibuat dari nol lewat sintesis audio, bukan rekaman dari situs lain. **Bebas dipakai untuk apa pun, termasuk konten komersial dan monetisasi, tanpa perlu mencantumkan kredit.**

## Daftar suara

| File | Suara | Durasi |
| --- | --- | --- |
| `pop-huruf-1.mp3` … `pop-huruf-4.mp3` | "Pop" kecil, 4 nada berbeda. Untuk huruf atau elemen yang muncul satu per satu | 0,2 dtk |
| `pop-besar.mp3` | "Pop" lebih tebal untuk elemen utama yang muncul | 0,4 dtk |
| `kertas-kresek-pendek.mp3` | Kertas diremas atau digeser sebentar | 0,6 dtk |
| `kertas-kresek-panjang.mp3` | Kertas bergerak cukup lama, cocok sebagai latar adegan | 2 dtk |
| `kertas-dibalik-1.mp3`, `-2.mp3` | Kertas dibalik atau dilipat, diakhiri bunyi "tak" | 0,4 dtk |
| `pin-ditancap.mp3` | Pin ditancapkan ke peta | 0,3 dtk |
| `label-jatuh-1.mp3` … `-3.mp3` | Kertas jatuh lalu mendarat "tuk", 3 variasi | 0,5 dtk |
| `tik-angka.mp3` | Satu bunyi "tik" | 0,1 dtk |
| `tik-angka-1892.mp3` | 4 bunyi "tik" berurutan dengan nada naik, untuk angka yang terbentuk | 0,7 dtk |
| `whoosh-transisi.mp3` | Desir transisi antaradegan | 0,8 dtk |
| `whoosh-cepat.mp3` | Desir singkat untuk gerakan cepat | 0,4 dtk |
| `ombak-laut-loop.mp3` | Ombak laut lembut, bisa diulang (loop) | 6 dtk |
| `klakson-kapal.mp3` | Klakson kapal uap | 1,6 dtk |
| `ding.mp3` | Bunyi "ding" untuk penutup atau ajakan komentar | 1,5 dtk |

## Contoh penempatan: video "Kenapa pasta gigi disebut odol?"

| Detik | Adegan | Efek suara |
| --- | --- | --- |
| 0–3 | Tube kertas, huruf "ODOL?" muncul | `kertas-kresek-pendek` di awal, lalu `pop-huruf-1` sampai `-4` untuk tiap huruf O-D-O-L, dan `pop-besar` untuk "?" |
| 3–12 | Peta Eropa, pin di Jerman, angka 1892 | `whoosh-transisi` saat peta masuk, `pin-ditancap` saat pin menempel, `tik-angka-1892` saat angka terbentuk |
| 12–22 | Kapal kertas berlayar ke Nusantara | `ombak-laut-loop` sebagai latar dengan volume kecil, `klakson-kapal` saat kapal mulai bergerak, `kertas-kresek-panjang` saat kapal bergeser |
| 22–32 | Label ODOL, AQUA, SANYO berjatuhan | `label-jatuh-1`, `-2`, `-3`, satu file untuk tiap label |
| 32–40 | Tangan menaruh tanda tanya | `kertas-dibalik-1` saat tangan masuk, `ding` saat tanda tanya diletakkan |

## Tips di CapCut

- Turunkan volume efek suara ke sekitar **30–50%** supaya voice-over tetap jelas.
- Untuk `ombak-laut-loop`, cukup 15–20%, karena fungsinya hanya suasana.
- Geser efek suara **1–2 frame lebih awal** dari gerakan di video supaya terasa pas di telinga.
